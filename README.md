# M3Food Organic Bright Bangla Landing Page v1.6.5

এই সংস্করণে গ্রাহক ভিডিও রিভিউ একবারে একটি করে দেখানো হয়, পুনরাবৃত্ত অফার টিকার সরানো হয়েছে, অর্ডার ফর্মের পরিমাণ নির্বাচন নতুন করে ডিজাইন করা হয়েছে এবং বড় পুনরাবৃত্ত অর্ডার কার্ডের বদলে কমপ্যাক্ট নিশ্চিতকরণ বোতাম রাখা হয়েছে।

## Run

```powershell
npm install
npm run dev
```

তারপর `http://localhost:3000` খুলুন।
